# 隐私与备份

更新日期：2026-10-20，适用于 `1.6.23-oss`。

无需注册或登录；词库、进度、收藏、设置、学习统计和个人复习参数保存在本机。自动调整复习在本机计算，不调用外部模型、不上传学习记录。当前没有广告或行为分析 SDK。

拍照查词使用本机 ML Kit Latin 模型识别英文，相机权限仅用于用户主动使用该功能。通知权限用于每日学习提醒。英文发音优先播放本机缓存。用户在「我的 → 发音偏好」填写自己的火山引擎 API Key 后，有网且未缓存的英文单词会发给火山引擎语音合成，取回发音并缓存在本机；Key 使用 AndroidKeyStore 加密保存在应用私有目录，不进入 JSON、系统云备份或换机传输，删除 Key 不清理音频缓存。未配置 Key、没网或请求失败时，使用安装包内的 Piper 离线语音。中文释义仍由设备 Text-to-Speech 朗读。

标准 Android 云备份只包含设置等允许项，排除词库与学习数据库、会话密文、设备标识和语音 Key 密文。设备间传输规则允许数据库迁移，但实际云备份与换机行为没验证。

请通过「我的」导出 JSON，保存完整学习副本。第 5 版备份包括设置、进度、作答、会话、个人复习参数、词义 / 听写 / 拼写 / 例句分项状态、未完成练习计划、双测断点和词条身份信息，支持读取第 1～4 版；内容不合法时整份拒绝，保留本机数据。恢复会整体替换相应记录；旧格式不包含的会话或个人参数按相应兼容规则重置。请保留恢复前的副本。词库不同的原版备份不能保证与开源示例版匹配。

清除应用数据或卸载会删除本机应用记录；已导出的备份仍留在保存位置，需自行管理。不要在公开 Issue 中上传个人备份。
