# 隐私与备份

更新日期：2026-10-14，适用于 `1.6.7-oss`。

无需注册或登录；词库、进度、收藏、设置、学习统计和个人复习参数保存在本机。自动调整复习在本机计算，不调用外部模型、不上传学习记录。当前没有广告或行为分析 SDK。

拍照查词使用本机 ML Kit Latin 模型识别英文，相机权限仅用于用户主动使用该功能。通知权限用于每日学习提醒。发音使用设备 Text-to-Speech，是否联网取决于用户选用的语音引擎与语音包。

标准 Android 云备份只包含设置等允许项，排除词库与学习数据库、会话密文和设备标识。设备间传输规则允许数据库迁移，但实际云备份与换机行为没验证。

请通过「我的」导出 JSON，保存完整学习副本。第 3 版备份包括设置、进度、作答、会话和个人复习参数，支持读取第 1、2 版。恢复会整体替换相应记录；旧格式不包含的会话或个人参数按相应兼容规则重置。请保留恢复前的副本。词库不同的原版备份不能保证与开源示例版匹配。

清除应用数据或卸载会删除本机应用记录；已导出的备份仍留在保存位置，需自行管理。不要在公开 Issue 中上传个人备份。
