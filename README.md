Alan 背单词围绕一件事设计：**让你从认识一个词，走到能自己想起来，再通过复习把它留下来。**

选好词书，设定每天愿意花的时间，打开首页就知道接下来学什么。新词怎么练、哪些旧词该复习、答错后什么时候再见，应用会按你的学习记录安排。你只需要专心完成眼前这一题。

> **当前开源版包含完整学习程序和 2 本、共 40 词的示例词书。** 原版第三方词库的再分发授权尚未确认，因此没有收入本仓库。可按[词库格式](docs/DATA_SOURCES.md)加入自己有权使用和分发的数据后构建。

## 为什么简单好用

| 你关心的事 | Alan 怎样处理 |
| --- | --- |
| 打开后学什么？ | 首页给出当天任务，优先复习旧错弱词和到期词，再安排新词。 |
| 每天学多少合适？ | 结合每日目标、可用时间、复习量和近期实际用时，控制新词数量。 |
| 要自己设置复习日期吗？ | 根据每个词的回忆表现安排下一次复习。 |
| 写错以后怎么办？ | 保留本次输入，标出错误，看到正确拼写后手动继续，留出看清和纠正的时间。 |
| 中途有事离开？ | 学习进度和练习状态保存在本机，支持继续学习。 |
| 需要账号或订阅吗？ | 当前版无需注册或登录，没有广告或行为分析 SDK。 |
| 数据怎样保存？ | 进度、收藏和设置在本机；可以导出 JSON 备份，恢复时包含个人复习参数。 |

学习时进入专注页面，日常功能集中在首页、查词、复习、我的四个入口。**简单，来自应用替你安排重复事务，让每一步都有明确的下一步。**

## 怎样帮助你记住单词

### 1. 先建立联系，再主动回忆

新词从拼写、词义、发音和例句开始。看过之后，需要根据中文主动写出英文，并分别练习词义、听写和例句。

看中文默写时不会自动播放英文；主动点喇叭会记为使用提示。这样，应用能区分“独立想起来”和“提示后答出来”。练习中写对 3 次只表示本次练习通过，之后仍要接受测试与复习。

### 2. 听得出来，也知道意思

主线双测包含英文听写和中文释义两轮，检查不同方向的掌握情况。答错或薄弱的词会进入后续复习安排，减少只凭眼熟就跳过的情况。

### 3. 用第一次独立回忆决定复习

巩固排期看第一次没有提示时的回忆结果。当时没有想起来，即使随后练会，也会保留这次遗忘的记录，并在次日再查。

应用采用基于 FSRS-5 的排期，结合间隔、记忆稳定度与难度估计下次复习时间。已经熟悉的词也会到期复习，记忆需要持续检查。

### 4. 先照顾旧词，再学习新词

每天的主线依次考虑：

**旧错弱词复习 → 补漏双测 → 到期巩固 → 新词学习 → 新词双测**

当天没有任务的阶段会跳过。复习多的时候，新词量会相应减少；积累用时记录后，计划会参考近 14 天的实际练习速度。每天的目标不仅是增加学过的数量，也要给已经学过的词留出时间。

### 5. 让复习逐步适应你

“自动调整复习”默认开启。积累足够的独立回忆记录后，应用在手机充电、空闲时，在本机校准 FSRS-5 的两个参数。新参数须在留出的较晚记录上通过验证才会采用；支持回退，也可以关闭。

这项智能化直接服务于复习安排，使用时无需管理模型或输入提示词。计算不上传学习记录，也不调用外部 AI 服务。

**当前实现是 FSRS-5 两参数校准，并非完整参数优化器。** 至少需要 400 条可评分样本、40 个不同单词和 30 天跨度等条件，刚开始使用时采用默认参数。真实学习者的长期效果尚未验证，不承诺固定的记忆提升幅度。详见[自动调整复习](docs/AUTO_RETENTION_PERSONALIZATION.md)。

## 开始使用

1. 构建并安装应用，选择示例词书与单元。
2. 设置每日目标和愿意投入的时间。
3. 从首页开始当天任务，按提示学习、测试、复习。
4. 在「我的」定期导出 JSON 备份，保存在自己能找到的地方。

还提供中英文查词、拍照或相册识别英文、收藏、学习统计、深色模式和每日提醒。发音使用 Android Text-to-Speech；能否完全离线及可用口音，取决于设备语音引擎和语音包。

开源版应用 ID 为 `com.alanbeidanci.opensource`，可与原版并存，使用独立的数据空间。**不要把原版完整词库备份导入示例版来迁移学习记录**：词库不同，无法保证进度匹配。本仓库不提供原版签名密钥或原版 APK；当前也没有正式签名发布包。

## 开发与构建

Kotlin / Jetpack Compose / Room / DataStore / WorkManager。Android 8.0（API 26）及以上；compile / target SDK 36。当前版本 `1.6.7-oss`。

准备 JDK 21、Android SDK Platform 36 和 Build Tools 36.0.0。在 `local.properties` 设置 `sdk.dir`，或配置 `ANDROID_HOME`。项目自带 Gradle Wrapper 9.5.0，首次构建需要联网下载依赖。

```bash
git clone https://github.com/mushroomfk/alan-vocab-android.git
cd alan-vocab-android
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew assembleRelease
```

Debug 安装包：`app/build/outputs/apk/debug/app-debug.apk`。Release 输出：`app/build/outputs/apk/release/app-release-unsigned.apk`，需要开发者使用自己的密钥签名。

设备回归测试会清空测试应用的学习数据与设置，只能对独立模拟器执行，并明确指定设备：

```bash
ANDROID_SERIAL=<独立模拟器序列号> ./gradlew connectedDebugAndroidTest
```

验证结果与未验证范围见 [CHANGELOG](docs/CHANGELOG.md)。旧联网版的部分实现仍保留在源码中，但 `LOCAL_ONLY=true`，未接入当前导航；原服务地址和自定义服务器证书已移除。
